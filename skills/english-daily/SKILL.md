# 英语每日课

面向零基础学习者的每日英语课。上课内容按课次归档为 md 笔记，每 7 课一份文件；阅读材料单独放在 read 目录，一天一个文件；总目录与摘要（`INDEX.md` / `digest.md`）由后端数据更新，看板是纯 API 驱动的静态页；难度随用户对当课的反馈升级或降级。

## 一、工作目录

默认固定使用 `E:\English`。用户另有指定时以指定目录为准，并在之后所有脚本调用中用 `--root` 传入同一个目录。

```text
E:\English\
├─ INDEX.md            总目录（后端数据更新，不手工改）
├─ digest.md           学习摘要（后端数据更新，上课时只读这份）
├─ progress.md         进度与级别（模型维护）
├─ wrong-words.md      错词本（模型追加）
├─ notes\              课程笔记，每 7 课一份
│   ├─ day-01-07.md
│   ├─ day-08-14.md
│   └─ ...
├─ read\               阅读材料，一天一个文件
│   ├─ 2026-09-26-read.md
│   └─ ...
├─ records\            归档产出（机器契约，本人产出、后端只读）
│   ├─ lesson-06.grading.json
│   ├─ lesson-06.backfill.json
│   ├─ lesson-06.record.json        LessonRecord（第 8 步归档产出）
│   └─ ...
└─ review\             前端静态页，纯 API 驱动，数据实时来自后端
    ├─ index.html      看板首页（统计、入口、课程总结）
    ├─ reading.html    阅读页
    ├─ words.html      词汇卡页
    ├─ wrong.html      错词本页
    └─ lessons\
        └─ lesson-1.html   每课详情页
```

**仓库内依赖（重要）**：本 Skill 的教学规则（级别判定、降载档位与触发、出题与批改口径）以仓库内 **`docs/ai-teacher.md`** 为唯一权威来源。该文件缺失或版本不符时，本 Skill 无法正确判档与出题——**它只能在包含 `docs/ai-teacher.md` 的仓库内运行**。若要打包分发给仓库外使用，必须连同该文件一起带上；若运行时发现该文件不存在，应**明确提示依赖缺失并停止**，不得凭默认值硬跑。

## 二、触发与路由

| 用户说 | 执行 |
|---|---|
| 上课 / 开始今天的英语课 / 今天学英语 / 下一课 / 继续 / 英语每日课 | 走上课流程 |
| 上次学到哪了 / 我的进度 | 读 progress.md 与 INDEX.md，汇报课号、级别、最近三课主题、下次要复习的内容 |
| 生成复习看板 / 看板 / 我要复习 | 打开 `review\index.html`——纯 API 驱动静态页，数据实时来自后端，无需任何重建 |
| 复习错词 / 错词 | 从 wrong-words.md 取未过关项出 5 题，批改后更新连续答对次数 |
| 重新出今天的阅读 / 换一篇阅读 | 覆盖重写当天的 read\YYYY-MM-DD-read.md |
| 今天我想学 X | 把 X 作为当日课程主题，仍走完整上课流程 |

notes 目录为空（首次使用）时，先运行 init_workspace.py 再上课。

## 三、上课流程

按顺序执行。标注「等待」的步骤必须停下来等用户回复，不得一次把整课输出到底。

1. 读取状态：只读 `digest.md`（含当前级别、已上课数、最近三课摘要、全部课号一览、错词未过关项、阅读清单）和 `progress.md`（级别、连击计数、待补清单）。**不要读 notes 全文**，只在需要核对某课原文时，按 `digest.md` 里给出的文件名单独读那一个文件。课号以 notes 中的实际最大课号为准，两者不一致时在回复里说明已按笔记修正。
2. 定课号：本课号 N = 实际最大课号 + 1。目标文件为 `notes\day-{起始:02d}-{结束:02d}.md`，其中起始 = ((N-1)//7)*7+1，结束 = 起始 + 6。
3. 出复习题（等待作答）：从四处取 3—5 题——第 N-1 课一题、第 N-3 课一题、第 N-7 课一题，其余取错词本未过关项（`digest.md` 已列好，可直接取用）。课号小于等于 0 的项跳过。题目只出现在对话里，不写进笔记。
4. 批改复习：逐题判定。答错项在 `wrong-words.md` 中 `累计犯错` 累加、`连续答对` 清零；答对则 `连续答对` +1，达到 2 次标记「已过关」，不再进入每日复习队列。判重与列口径见第七章。**新课的课前复习由写接口直接落库，不产出 `records/lesson-NN.review.json`**——该文件只用于旧课回填。
5. 讲新课（等待作答）：**先按下方「降载判定」算出本课档位**（定生词数、是否讲新点、复习题量），再按 `references/level-map.md` 取当前级别的下一个知识点。固定内容量——1 个语法点 + 生词数量按当前级别与档位取：Level 1 常规 5—8 个；Level 2 常规 10 个（区间 8—12），触发降载时 6—8 个（**触发条件与档位以 `docs/ai-teacher.md` §7.4 为准**）（含音标和中文）+ 3—5 个例句 + 3 道小题 + 1 道开放题（造句或写 5 句左右的小段）。总量控制在 20—30 分钟，不允许一课塞进两个语法点。
6. 收作业（等待作答）：用户提交后逐题批改，每题指出错误类型（语法 / 拼写 / 用词）、给出正确句、附一句解释。**同时产出机器契约文件，这是本步的硬性产物，不是可选项**：
   - `records/lesson-NN.grading.json` —— 本课**作业**逐题判定（`kind: "homework"`）。
   - `records/lesson-NN.backfill.json` —— 本课**有补漏块**时另出一份（`kind: "backfill"`）；没有补漏块就不出这个文件。
   - **作业与补漏块必须分成两个文件**：两套题号各自从 1 开始，错误计数口径也不同（补漏块错误单列 `summary.backfillErrorCount`，不计入作业 `errorCount`）。
   - 字段与写法以 `records/README.md` 为准（`verdict` → `is_correct` 的映射、`mistakeCandidates[]` 的形态见该文件第二节）。
   - **不得只写 `### 批改` 散文而不产出 JSON**：后端禁止解析散文，而「两处错误。用词：…；语法：…」这类写法无法可靠映射到题号与错误类型，文本匹配必然产出假数据。
7. 收反馈（等待作答）：问「这课太简单 / 刚好 / 太难？」，等用户回答后更新 `progress.md` 的级别与反馈记录。
8. 归档（**三件产出，缺一不可**）：
   - **追加写 md**：把第 5—7 步的内容**追加**到目标 `notes/` 文件末尾，只追加，不重写、不删除已有内容。
   - **更新 `wrong-words.md`**：按第七章口径（新错词追加整行，含人工判定的 `类型` / `累计犯错`）。
   - **产出 `LessonRecord`（机器契约）**：按 `docs/schemas/lesson-record.schema.json` 组装本课归档对象（`lessonNo` / `levelCode` / `summary` / `sections` / `vocabulary` / `exercises` / `feedback` / `gradeSummary` / `nextRecommendation`）。**对象由本步已在手的教学内容直接组装 —— 不解析 md、不拼 HTML**。
     - `deploymentMode = backend`（写接口就绪）→ 经 `POST /lessons` 提交；批改与反馈回填走 `PUT /lessons/:id`。
     - `deploymentMode = markdown`（当前）→ 落盘 `records/lesson-NN.record.json`，供后端就绪后提交。
   - **md 与 `LessonRecord` 的关系**：md 是 `LessonRecord` 的**人类可读落地形式**（两者内容须一致）；**真相源是 `LessonRecord`**（口径见 `docs/skills.md` §7.2）。**md 不再作为任何导入管线的输入**。
9. 生成当日阅读：看 `read\YYYY-MM-DD-read.md`（当天日期）是否存在——
   - 不存在：按当前级别生成 1—3 篇，写进这个文件。
   - 已存在：不改动它。同一天上第二次课不会再生成，也不会覆盖。
   - 用户说「重新出今天的阅读」时才覆盖重写。
10. 汇报：告诉用户本课编号、写入的文件、当天阅读文件路径、下次课会复习什么、当前级别。

### 降载判定（第 5 步前置，规则见 `docs/ai-teacher.md` §7.4）

**降载 ≠ 降级**：降载是**保持级别、只减本课负荷**（降级见第五章）。每课讲新课前先算下列**可自动计算**的量；命中任一触发即降载，命中多档取最高，一次最多下调 1 档。

| 量 | 怎么算 |
|---|---|
| `E` | 上一课（或最近 2 课）的作业错误处数，等价 `lessons.error_count` / `study_records(grade).payload.errorCount`；只计今日语法作业（`kind='homework'`）中 `verdict=wrong` 的处数 |
| `D` | 断更天数 = 今天 − `progress.md`「上次上课」日期 |
| `F` | 上一课自评反馈（太简单 / 刚好 / 太难） |
| `W` | 错词本未过关项的 `wrongCount`（`digest.md` 已列，可直接取） |
| 拟排生词数 | 本课计划排入的生词个数 |

**触发**（任一命中即降载，取最高档）：T-1 单课超阈 `E >= 5`；T-2 连续超阈（最近 2 课均 `E >= 5`）；T-3 反馈过难 `F = too_hard`；T-4 断更 `D >= 7`；T-5 复发阻断（存在 `W >= 4` 且 `error_type ∈ {grammar, word_choice}` 的未过关错词）；T-6 超载上限（拟排生词 > 12）。

**档位**（生词数 / 练习量 / 是否讲新点 / 阅读篇数**以 `docs/ai-teacher.md` §7.4 档位表为准**，下表仅摘要）：

| 档 | 命中 | 生词 | 新知识点 | 复习题量 |
|---|---|---|---|---|
| **L0 常规** | 无触发 | 按本级别常规档 | 1 个新点，家族一次讲全 | 5 题 |
| **L1 轻度** | T-1（`E`=5—6）/ T-3（`too_hard` 且 `E<=5`）/ T-4（`D`=3—6） | 6—8（Level 2） | 保留，但只讲「肯定 + 否定」 | 5—7 题 |
| **L2 中度** | T-1（`E>=7` 且非新点首课）/ T-2 / T-4（`D>=7`） | 0—6（复现旧词为主） | **不讲新点**，改「同点变式」重讲 1 个已学点 | 8—10 题 |
| **LX 阻断** | T-5 | 0（全复用） | 不讲新点，专项攻该错点 | 6—8 题 |

**边界（不可省）**：
- **上限保护**：已在 L2 / LX 仍 `E >= 5` → 不再继续降载，转 `docs/ai-teacher.md` §7.2 的诊断 / 降级评估。
- **D1 例外（防误伤）**：新语法点**首课** `E >= 6` 属「新点首课冲高」，**不降载**，下一课用同点变式复练。
- **退出**：降载后连续 2 课同时 `E <= 2` 且 `R = 0`（无复发项）且 `F ∈ {too_easy, just_right}` → 退出降载、生词恢复常规档；第 1 课先升半档，任一课 `E >= 5` 回退一档重算。
- 降载 / 退出状态写进下一课 `next_recommendation`，便于复盘。

**不由 Skill 自动决定**（交 Amy / 上课时人工判断，勿自行推断）：`R`（本课复发项个数，依赖批改结果）、L2 / LX 的「同点变式」具体怎么出题、L1 复习题量是否取上限 7、书写规范类错误的题型拆分（该拆分类错误不单独触发降级 / 降载）。

## 四、笔记格式

每课笔记按 `references/course-template.md` 写，必须包含下列小节，标题文字不得改动（后端按标题解析）：

`## 第 N 课 · YYYY-MM-DD` → `> 一句话：…` → `### 复习` → `### 今日语法` → `### 词汇` → `### 例句` → `### 作业` → `### 我的作答` → `### 批改` → `### 难度反馈`

阅读不写进课程笔记，一律写进 `read\YYYY-MM-DD-read.md`。

日期规则：按课次编号，断更不断号；**同一天里的第一次课**在标题标出当天日期，同一天的第二课起只写 `## 第 N 课`，不重复标日期。

## 五、级别与升降级

- 初始为 Level 1（零基础）。各级别的知识点顺序、词汇量、阅读长度见 `references/level-map.md`。
- 连续 2 次反馈「太简单」→ 升 1 级，计数清零。
- 任意 1 次反馈「太难」→ 降 1 级，且之后 3 课内不再升级。
- 反馈「刚好」→ 维持级别。
- 用户明确要求「拉快 / 拉慢」→ 直接调整级别，并在 progress.md 记录原因。

## 六、阅读规则

- 存放：`read\YYYY-MM-DD-read.md`，一天一个文件，当天 1—3 篇用 `## 第 1 篇 · 标题` 分隔。文件格式见 `references/course-template.md`。
- 生成时机：课后自动生成一次；当天文件已存在就跳过，不覆盖。
- Level 1—2：自编极简短文（30—60 词），只用已学词汇和句型，出现新词必须给中文注释。
- Level 3：自编或改编短文（80—120 词），主题为日常场景。
- Level 4—5：先用联网搜索找一条当日英文新闻，再**按当前级别改写**成 80—180 词的可读版本，保留原文标题、来源与链接。不得把未改写的原版新闻直接丢给用户，除非用户明确说「给我原文」。
- 网络不可用或搜不到当日新闻 → 降级为自编同级短文，并在「来源」一行写明「自编（当日新闻获取失败）」。不编造新闻内容，不用旧新闻冒充当日新闻。
- 每篇必须附：标题、级别、来源、3—6 个生词注释、2 道理解题（答案用 `<details>` 折叠）。
- **每道理解题的答案必填**：`answer` 必须是非空字符串。归档前自检「题数 ≥ 2 且每题答案非空」，**不达标则该篇整体重写，不留空答案、不产 `null` / 空串**；拟不出可判定答案的问题**不写成理解题**（需要练开放表达就放作业的开放题）。依据 `docs/ai-teacher.md` §11.10。

## 七、错词本（`wrong-words.md`）

错词本是错词的**手工真相源**。它写的 `错误点` / `类型` / `累计犯错` 必须与 `records/*.json` 和数据库三处**逐字一致**——不一致会让迁移把同一条错拆成两行。

### 运行时必做（权威规则见 `docs/ai-teacher.md` §11）

错词与批改（权威规则见 `docs/ai-teacher.md` §11，本处只列运行时必做）：

```text
1. 出题顺序：wrongCount≥3 每课至少 1 题 → N-1/N-3/N-7 各 1 题 → streak==1 优先 → 其余按 wrongCount 降序。
2. 判对错：答对 streak+1（≥2 判过关）；答错 wrongCount+1 且 streak=0。
3. 判重键：去标点、去空格、统一小写后的 wrongText；命中只累加，不新建条目。
4. errorType 由 Amy 人工判定（三步判定见 §11.5）；判不出归 other 并标「待人工复核」。
5. 批改完成必须同时产出 records/lesson-NN.grading.json（作业）与 lesson-NN.backfill.json（补漏块）。
说明：错词本「错误点」列只写错误形式本身，批注写进「错因」列。
```

出题顺序用**教学排序**，不是服务端 `priority` 展示排序，两者允许不同（见 `docs/ai-teacher.md` §11.9）；断更补课的题量上浮档依赖后端 `lastIncomplete`（G4，未实现），**未落地前一律按常规 5 题**。

表头固定 8 列，列名、顺序、写法都不得改动：

| 列 | 含义 | 谁填 |
|---|---|---|
| 课号 | 首次出现的课号；诊断来源写「诊断」 | 人工 |
| 错误点 | **只写错误形式本身**（见下） | 人工 |
| 正确形式 | 最小修正形式 | 人工 |
| 错因 | 一句中文，含复发次数与场景说明 | 人工 |
| 连续答对 | 达 2 即过关 | 人工 / 写接口 |
| 状态 | `未过关` / `已过关` | 人工 / 写接口 |
| 类型 | `error_type`，6 值枚举，判定见 `docs/ai-teacher.md` §11.5 | **仅人工判定** |
| 累计犯错 | `wrong_count`，累计到 3 次触发下一课强制自查项 | **仅人工判定** |

### `错误点` 只写错误形式（硬规范）

**只写错误形式本身，不带任何括号批注。** 批注（复发次数、出现场景、题目要求）一律写进 `错因` 列。

| 反例（带批注） | 正例 |
|---|---|
| `zane（人名小写）` | `zane` |
| `Do you like coffee.（句号结尾）` | `Do you like coffee.` |
| `play game（第 3 次犯：第 6 课写 were playing game）` | `play game` |
| `at yesterday（I was busy at yesterday）` | `at yesterday` |
| `what do you do?（问「正在做什么」时）` | `what do you do?` |

**为什么必须这样**：`错误点` 就是判重键 `uk_mistakes_text (student_id, wrong_text)` 的取值。批注一混进去，同一个错误在错词本与 `records/*.json` 里就不是同一个字符串，迁移时按该唯一键**会把一条错拆成两行**（DQ1 幂等迁移的根源：重跑一次多一行）。

**不要把「错误」改掉**：句尾标点、句首大小写、拼写本身可能就是错误点，按原样保留，不要顺手修正成正例形式。

### `类型` / `累计犯错` 不得推导

这两列**无法从其他列算出来**：`类型` 是按「错误主体」三步判定的人工结论（`docs/ai-teacher.md` §11.5），`累计犯错` 是跨课累计值。**任何脚本、解析器或模型都不得用规则、文本匹配或统计去猜这两列**——猜错会让类型分布与复发阈值同时失真。确实判不出时留空并在对话里说明，**不要填默认值**。

### 更新时机

- **复习批改（第 4 步）**：答错 → 对应行 `累计犯错 +1`、`连续答对 = 0`；答对 → `连续答对 +1`，达 2 标记「已过关」退出每日复习队列。
- **作业批改（第 6 步）**：新错词按上表**追加整行**（含人工判定的 `类型`）；判重命中已有行则只累加，不新建。
- 只追加，不重写、不批量改写历史行。

### 与 `records/*.json` 的关系

- `records/*.json` 的 `mistakeCandidates[]` 是「判错证据」，**候选 ≠ 入册行**：是否进错词本由人工决定。课前复习与诊断测试不在 records 覆盖范围内，其错词只出现在错词本里。
- 两处的文本**必须一致**（records 侧判重用「去标点、去空格、统一小写」后的比较），但**数量可以不等**。以错词本为准：`类型` 与 `累计犯错` 两列的权威值只在这里。

## 八、脚本

两个脚本只依赖 Python 标准库，需要 Python 3.10 及以上，用 `python scripts\<脚本名>.py --root E:\English` 调用。

1. `check_environment.py`：只读检查 Python 版本、目录写权限、网络连通性（用于当日新闻）。输出 `ENV_STATUS=ready|partial|needs_setup|unavailable` 与逐项结果；退出码 0 表示 ready/partial，1 表示 needs_setup，2 表示 unavailable。
2. `init_workspace.py`：创建 notes、read、review 目录与初始文件，已存在的文件一律不覆盖。首次使用或目录被误删后运行，输出 `INIT_OK`。

`INDEX.md` 与 `digest.md` 由后端数据更新，本 Skill 不产出这两个文件；上课时照旧只读 `digest.md`，不要读 notes 全文。`digest.md` 正常稳定在 2—4KB，超过 8KB 时提醒用户清理旧课细则。

## 九、质量自查清单

每次下课前逐条对照：

- [ ] 复习题取自 N-1 / N-3 / N-7 或错词本，不是临时编的新内容
- [ ] 作业已批改，错误类型、正确句、解释三项齐全
- [ ] 已产出 `records/lesson-NN.grading.json`（本课有补漏块时另有 `lesson-NN.backfill.json`）
- [ ] 已产出 `LessonRecord`（按 `docs/schemas/lesson-record.schema.json`）：写接口就绪（`deploymentMode = backend`）时已成功提交，否则已落盘 `records/lesson-NN.record.json`
- [ ] `wrong-words.md` 的 `错误点` 只写错误形式、无括号批注，`类型` / `累计犯错` 已填且为人工判定值
- [ ] 笔记小节齐全、课号连续、只在文件末尾追加
- [ ] 笔记里没有「今日阅读」小节，阅读只写在 read 目录的当天文件里
- [ ] 当天阅读文件已生成（或当天已存在而跳过），每篇都有级别、来源、生词注释、理解题
- [ ] 已收到难度反馈并写入 progress.md
- [ ] 本课笔记已按模板归档（目录与摘要由后端数据更新，本 Skill 不产出这两个文件）
- [ ] 已读 `digest.md` 而非 notes 全文（除核对单课原文外）
- [ ] 内容量不超过 30 分钟

## 十、停止条件

- 用户未作答时不推进下一环节，不替用户写作业答案。
- 网络不可用时不编造「今日新闻」，改自编短文并如实标注来源。
- 当天阅读文件已存在时不覆盖，除非用户明确要求重出。
- 不手工改 `INDEX.md`、`digest.md` 与 `review` 下的 html：前者由后端数据更新，后者是纯 API 驱动的静态页。
- 不删除、不重命名、不移动任何已有笔记和阅读文件；需要调整时先向用户说明并等确认。
