# 英语每日课

面向零基础学习者的每日英语课。上课内容按课次归档为 md 笔记，每 7 课一份文件；阅读材料单独放在 read 目录，一天一个文件；总目录与看板由脚本重建；难度随用户对当课的反馈升级或降级。

## 一、工作目录

默认固定使用 `E:\English`。用户另有指定时以指定目录为准，并在之后所有脚本调用中用 `--root` 传入同一个目录。

```text
E:\English\
├─ INDEX.md            总目录（脚本重建，不手工改）
├─ digest.md           学习摘要（脚本重建，上课时只读这份）
├─ progress.md         进度与级别（模型维护）
├─ wrong-words.md      错词本（模型追加）
├─ notes\              课程笔记，每 7 课一份
│   ├─ day-01-07.md
│   ├─ day-08-14.md
│   └─ ...
├─ read\               阅读材料，一天一个文件
│   ├─ 2026-09-26-read.md
│   └─ ...
└─ review\
    ├─ index.html      看板首页（脚本重建，只放统计、入口和课程总结）
    ├─ reading.html    阅读页（脚本重建）
    ├─ words.html      词汇卡页（脚本重建）
    ├─ wrong.html      错词本页（脚本重建）
    └─ lessons\
        └─ lesson-1.html   每课详情页（脚本重建）
```

## 二、触发与路由

| 用户说 | 执行 |
|---|---|
| 上课 / 开始今天的英语课 / 今天学英语 / 下一课 / 继续 / 英语每日课 | 走上课流程 |
| 上次学到哪了 / 我的进度 | 读 progress.md 与 INDEX.md，汇报课号、级别、最近三课主题、下次要复习的内容 |
| 生成复习看板 / 看板 / 我要复习 | 只运行 build_board.py，然后打开 review\index.html |
| 复习错词 / 错词 | 从 wrong-words.md 取未过关项出 5 题，批改后更新连续答对次数 |
| 重新出今天的阅读 / 换一篇阅读 | 覆盖重写当天的 read\YYYY-MM-DD-read.md |
| 今天我想学 X | 把 X 作为当日课程主题，仍走完整上课流程 |

notes 目录为空（首次使用）时，先运行 init_workspace.py 再上课。

## 三、上课流程

按顺序执行。标注「等待」的步骤必须停下来等用户回复，不得一次把整课输出到底。

1. 读取状态：只读 `digest.md`（含当前级别、已上课数、最近三课摘要、全部课号一览、错词未过关项、阅读清单）和 `progress.md`（级别、连击计数、待补清单）。**不要读 notes 全文**，只在需要核对某课原文时，按 `digest.md` 里给出的文件名单独读那一个文件。课号以 notes 中的实际最大课号为准，两者不一致时在回复里说明已按笔记修正。
2. 定课号：本课号 N = 实际最大课号 + 1。目标文件为 `notes\day-{起始:02d}-{结束:02d}.md`，其中起始 = ((N-1)//7)*7+1，结束 = 起始 + 6。
3. 出复习题（等待作答）：从四处取 3—5 题——第 N-1 课一题、第 N-3 课一题、第 N-7 课一题，其余取错词本未过关项（`digest.md` 已列好，可直接取用）。课号小于等于 0 的项跳过。题目只出现在对话里，不写进笔记。
4. 批改复习：逐题判定。答错项在 `wrong-words.md` 中累加错误次数并把连续答对清零；答对则连续答对 +1，达到 2 次标记「已过关」，不再进入每日复习队列。
5. 讲新课（等待作答）：按 `references/level-map.md` 取当前级别的下一个知识点。固定内容量——1 个语法点 + 生词（**数量按 `references/level-map.md` 当前级别的「每课词汇」行取，不得写死**）+ 3—5 个例句 + 3 道小题 + 1 道开放题（造句或写 5 句左右的小段）。总量控制在 20—30 分钟，不允许一课塞进两个语法点。
6. 收作业（等待作答）：用户提交后逐题批改，每题指出错误类型（语法 / 拼写 / 用词）、给出正确句、附一句解释。
7. 收反馈（等待作答）：问「这课太简单 / 刚好 / 太难？」，等用户回答后更新 `progress.md` 的级别与反馈记录。
8. 归档：把第 5—7 步的内容**追加**到目标 md 文件末尾，只追加，不重写、不删除已有内容。
9. 生成当日阅读：看 `read\YYYY-MM-DD-read.md`（当天日期）是否存在——
   - 不存在：按当前级别生成 1—3 篇，写进这个文件。
   - 已存在：不改动它。同一天上第二次课不会再生成，也不会覆盖。
   - 用户说「重新出今天的阅读」时才覆盖重写。
10. 重建看板：运行 `python scripts/build_board.py --root E:\English`。
11. 汇报：告诉用户本课编号、写入的文件、当天阅读文件路径、下次课会复习什么、当前级别。

## 四、笔记格式

每课笔记按 `references/course-template.md` 写，必须包含下列小节，标题文字不得改动（脚本按标题解析）：

`## 第 N 课 · YYYY-MM-DD` → `> 一句话：…` → `### 复习` → `### 今日语法` → `### 词汇` → `### 例句` → `### 作业` → `### 我的作答` → `### 批改` → `### 难度反馈`

阅读不写进课程笔记，一律写进 `read\YYYY-MM-DD-read.md`。

日期规则：按课次编号，断更不断号；**同一天里的第一次课**在标题标出当天日期，同一天的第二课起只写 `## 第 N 课`，不重复标日期。

## 五、级别与升降级

- 初始为 Level 1（零基础）。各级别的知识点顺序、词汇量、阅读长度见 `references/level-map.md`。
- 连续 2 次反馈「太简单」→ 升 1 级，计数清零。
- 任意 1 次反馈「太难」→ 降 1 级，且之后 3 课内不再升级。
- 反馈「刚好」→ 维持级别。
- 用户明确要求「拉快 / 拉慢」→ 直接调整级别，并在 progress.md 记录原因。

## 六、阅读规则

- 存放：`read\YYYY-MM-DD-read.md`，一天一个文件，当天 1—3 篇用 `## 第 1 篇 · 标题` 分隔。文件格式见 `references/course-template.md`。
- 生成时机：课后自动生成一次；当天文件已存在就跳过，不覆盖。
- Level 1—2：自编极简短文（30—60 词），只用已学词汇和句型，出现新词必须给中文注释。
- Level 3：自编或改编短文（80—120 词），主题为日常场景。
- Level 4—5：先用联网搜索找一条当日英文新闻，再**按当前级别改写**成 80—180 词的可读版本，保留原文标题、来源与链接。不得把未改写的原版新闻直接丢给用户，除非用户明确说「给我原文」。
- 网络不可用或搜不到当日新闻 → 降级为自编同级短文，并在「来源」一行写明「自编（当日新闻获取失败）」。不编造新闻内容，不用旧新闻冒充当日新闻。
- 每篇必须附：标题、级别、来源、3—6 个生词注释、2 道理解题（答案用 `<details>` 折叠）。

## 七、脚本

三个脚本只依赖 Python 标准库，需要 Python 3.10 及以上，用 `python scripts\<脚本名>.py --root E:\English` 调用。

1. `check_environment.py`：只读检查 Python 版本、目录写权限、网络连通性（用于当日新闻）。输出 `ENV_STATUS=ready|partial|needs_setup|unavailable` 与逐项结果；退出码 0 表示 ready/partial，1 表示 needs_setup，2 表示 unavailable。
2. `init_workspace.py`：创建 notes、read、review 目录与初始文件，已存在的文件一律不覆盖。首次使用或目录被误删后运行，输出 `INIT_OK`。
3. `build_board.py`：扫描 notes 与 read，重建 INDEX.md、`digest.md`、`review\index.html` 和 reading / words / wrong 三个专题页，以及 `review\lessons\lesson-N.html`。每课结束后运行一次，看板错乱时随时重跑。
   - 看板首页只放统计、三个入口（阅读 / 词汇卡 / 错词本）和每课的一句话总结，各专题内容都在各自的页面里，避免首页随课数无限膨胀。
   - `digest.md` 是上课时的唯一状态来源，含最近三课摘要、全部课号一览、错词待复习项、阅读清单。它由脚本整体重写，不要手工改。
   - `review\lessons\` 里的 lesson-*.html 与首页、专题页都由脚本每次重建：先删掉旧的 lesson-*.html 再重新生成，手工放进去的其他文件不受影响。
   - 成功输出 `BOARD_OK 课程数=<n> 阅读数=<n> 词汇数=<n> 摘要字节=<n>`；解析失败输出 `BOARD_FAIL 原因=<原因>` 且不改动任何已有文件，先修笔记格式再重跑。
   - 摘要字节数用于盯住 `digest.md` 的体积：正常应稳定在 2—4KB。超过 8KB 时说明该清理旧课的细则了，届时提醒用户。

## 八、质量自查清单

每次下课前逐条对照：

- [ ] 复习题取自 N-1 / N-3 / N-7 或错词本，不是临时编的新内容
- [ ] 作业已批改，错误类型、正确句、解释三项齐全
- [ ] 笔记小节齐全、课号连续、只在文件末尾追加
- [ ] 笔记里没有「今日阅读」小节，阅读只写在 read 目录的当天文件里
- [ ] 当天阅读文件已生成（或当天已存在而跳过），每篇都有级别、来源、生词注释、理解题
- [ ] 已收到难度反馈并写入 progress.md
- [ ] 已运行 build_board.py 且输出 BOARD_OK
- [ ] 已读 `digest.md` 而非 notes 全文（除核对单课原文外）
- [ ] 内容量不超过 30 分钟

## 九、停止条件

- 用户未作答时不推进下一环节，不替用户写作业答案。
- 网络不可用时不编造「今日新闻」，改自编短文并如实标注来源。
- 当天阅读文件已存在时不覆盖，除非用户明确要求重出。
- build_board.py 返回 BOARD_FAIL 时先修笔记或阅读文件的格式再重跑，不手工改 INDEX.md 和 review 下的 html。
- 不删除、不重命名、不移动任何已有笔记和阅读文件；需要调整时先向用户说明并等确认。
