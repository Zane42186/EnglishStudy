# 级别地图

五个级别，每课推进 1 个知识点。知识点按本文件的顺序取下一个，学生在某处卡住时可在同级内重复练同一类型，不跳到下一个。

## Level 1（零基础）

目标：能读懂和写出 5—10 词的最简单句，能做 5 句自我介绍。
每课词汇：5—8 个，累计约 80—100 词后进入 Level 2。
阅读：自编 30—60 词，只用已学词汇，出现新词必须给中文注释。

知识点顺序：

1. 主语 + 谓语 + 宾语（I like music）
2. be 动词 am / is / are
3. 人称代词主格与形容词性物主代词（I / my, you / your, he / his）
4. 一般现在时的第三人称单数 -s
5. 否定句 don't / doesn't
6. 一般疑问句 Do / Does 与简略回答
7. 名词单复数与 a / an
8. this / that / these / those
9. there is / there are
10. 疑问词 what / who / where
11. 情态动词 can
12. 祈使句与 Let's
13. 介词 in / on / at（时间与地点的最基础用法）
14. 一般现在时小结与自测

## Level 2（入门）

目标：能读懂 80 词左右的日常短文，能写 5—8 句连贯的话。
每课词汇：6—8 个。
阅读：自编或改编 80—120 词，主题为日常场景。

知识点顺序：

1. 现在进行时 am / is / are + -ing
2. 一般现在时与现在进行时的区别
3. 一般过去时 was / were
4. 规则动词的过去式
5. 常用不规则过去式（go-went、eat-ate、see-saw、have-had）
6. 过去时的否定与疑问 did
7. 将来时 will 与 be going to
8. 频度副词 always / usually / often / sometimes / never
9. 形容词比较级
10. 形容词最高级
11. must 与 have to
12. should（建议）
13. 连词 because / so / but
14. 时间状语从句 when

## Level 3（进阶）

目标：能读懂 120 词左右的简化材料，能写 100 词的小段。
每课词汇：8 个，开始引入词组搭配。
阅读：自编或改编 80—120 词，可取材于简化后的真实材料。

知识点顺序：

1. 可数与不可数名词，some / any / much / many
2. 现在完成时 have / has + 过去分词（基础用法）
3. 现在完成时与一般过去时的区别
4. 现在进行时表将来
5. 不定式 want to / need to / want sb to
6. 动名词 like doing / go doing
7. 宾语从句 that / what / where
8. if 真实条件句
9. 被动语态（一般现在时与一般过去时）
10. 反义疑问句
11. used to
12. 定语从句 who / which / that

## Level 4（提高）

目标：能读懂改写后的当日新闻（120—180 词），能写 150 词短文。
每课词汇：8 个，含新闻高频词。
阅读：当日英文新闻的改写版，120—180 词。

知识点顺序：

1. 过去进行时
2. 过去完成时（基础）
3. 现在完成进行时
4. 情态动词表推测 must / might / can't
5. 虚拟语气 if I were / would
6. 间接引语
7. 介词 + which / whom 的定语从句
8. 强调句 It is ... that
9. 分词作定语与状语
10. 名词性从句 whether

## Level 5（应用）

目标：能读懂 180—300 词的改写新闻与简化原版材料，能写 200 词观点段。
每课词汇：8—10 个，含抽象词与常见搭配。
阅读：当日新闻改写 180—300 词；用户明确要求时再给原文。

知识点顺序：

1. 名词性从句、定语从句、状语从句综合
2. 倒装与否定词的强调
3. 虚拟语气完成式 should have done
4. get + 过去分词与复杂被动
5. 让步、目的、结果状语从句
6. 连接副词与逻辑衔接（however、therefore、in addition）
7. 口语中的省略与缩略
8. 新闻与学术常用句式（It is said that、according to）

## 阅读存放规则

- 阅读一律写进 `read\YYYY-MM-DD-read.md`，一天一个文件，当天 1—3 篇，用 `## 第 N 篇 · 标题` 分隔。
- 不写进课程笔记。
- 课后生成一次；当天文件已存在就跳过，同一天再上课不覆盖，除非用户明确要求重出。

## 复习取材规则

每课的复习题按以下优先级取 3—5 题：

1. 第 N-1 课的知识点，一题
2. 第 N-3 课的知识点，一题
3. 第 N-7 课的知识点，一题
4. 错词本中状态为「未过关」的项，补足到 3—5 题

课号小于等于 0 的项跳过。题目用已学词汇，不引入本课还没讲的内容。

## 新闻改写规则（Level 4—5）

1. 用联网搜索找一条当日英文新闻，优先选事实清楚、多为 5W 要素（who / what / when / where / why）的报道，避开评论和长难句密集的文章。
2. 按当前级别改写：Level 4 每句不超过 15 词，Level 5 每句不超过 22 词。
3. 保留原文的事实、数字和专有名词，不做臆测和补充。
4. 保留原文标题、来源名称与链接，写在「来源：」一行，格式：`新闻改写（原标题：xxx | 来源：xxx | 链接：xxx）`。
5. 改写后附 3—6 个生词注释与 2 道理解题。
6. 搜不到当日新闻或网络不可用 → 改为自编同级短文，来源写「自编（当日新闻获取失败）」，不标注日期以外的时效信息。
